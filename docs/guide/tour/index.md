# Language tour

The language tour is being written. It will introduce Leech's syntax and implemented
features in five chapters:

1. Basics: functions, `main`, integer and boolean types, bindings and coercions.
2. Control flow: blocks, `if`, `while`, labeled loops, `match`, enums and tagged unions.
3. Data and pointers: structs, arrays, pointers and methods.
4. Modules and the standard library: imports, visibility, the prelude, `std::io` and
   `std::mem`.
5. Generics, traits and compile-time evaluation.

Until then, follow [Getting started](../getting-started.md) to build complete programs, or
return to the [user guide](../index.md).
