# Language tour

The tour introduces Leech's syntax and implemented features through complete programs. It
assumes you have installed `leech` as described in [Getting started](../getting-started.md),
and you may want to skim [Leech at a glance](../language-at-a-glance.md) first.

1. [Basics](01-basics.md): `main` and the exit status, functions, integer and boolean
   types, variables and conversions.
2. [Control flow](02-control-flow.md): blocks, `if`, `while`, labeled loops, `never`,
   enums, `match` and tagged unions.
3. [Data and pointers](03-data-and-pointers.md): structs, arrays, pointers, mutability and
   methods.
4. [Modules and the standard library](04-modules-and-stdlib.md): packages, imports,
   visibility, `extern`, the prelude, `std::io` and `std::mem`.
